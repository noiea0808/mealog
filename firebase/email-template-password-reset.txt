비밀번호 재설정 이메일 제목을 "project-숫자의 비밀번호 재설정" 대신 브랜드명으로 바꾸는 방법
================================================================================

Firebase Authentication이 보내는 비밀번호 재설정 메일의 제목·본문은
앱 코드가 아니라 Firebase 콘솔의 "이메일 템플릿"에서만 수정할 수 있습니다.

1. Firebase 콘솔(https://console.firebase.google.com)에서 해당 프로젝트 선택
2. 왼쪽 메뉴: Authentication(인증) → Templates(템플릿) 또는 이메일 템플릿
3. "Password reset"(비밀번호 재설정) 템플릿 편집
4. Subject(제목)를 예를 들어 다음처럼 변경:
   Mealog의 비밀번호 재설정
5. 저장

이후 발송되는 메일 제목이 위에서 설정한 문구로 표시됩니다.
