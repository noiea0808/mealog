프로필(마이) 시안 v2

현재 마이는 폼·카드·밀당 진입이 한 화면에 겹쳐 위계가 흐립니다. 라운지·모먼트와 같은 토큰으로, 정체성 히어로 → 편집 행 → 보조 설정으로 정리한 제안입니다.

허브 밀당 모먼트 밀로그 라운지 폰만

이 시안에서 바꾼 것

  • 1뷰포트 = 나 큰 아바타(그림자·Gmarket 이니셜) + 닉네임 + 한 줄 소개 + 「내 게시물」. 필드 나열·「홈으로」버튼 제거.
  • 밀당은 발견용 타일 프로필 본문과 경쟁하지 않게 soft-green 그라데이션 한 줄. (밀당: 하단 네비 첫 번째 메뉴)
  • 편집은 행(row)으로 닉네임·생일·소개를 라벨|값|chevron 리스트로. 빈 값은 muted 플레이스홀더만.
  • 라이프스타일 칩 = 라운지 톤 선택 시 solid green (검정 칩 폐기).
  • 서브탭 컴팩트 4등분 · soft-green · 선택 텍스트 검정 · 낮은 높이. 태그·푸시·메모는 각 패널에서만 깊이 있게.
  • 위험 액션은 아래로 로그아웃은 ghost, 탈퇴는 작은 danger. 버전은 푸터 한 줄.
