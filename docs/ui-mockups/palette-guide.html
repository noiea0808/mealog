Soft Mint Air 팔레트

현재 앱·시안 v2에 적용된 기본 톤입니다. 밝고 가벼운 민트 그린을 브랜드 축으로 두고, 코랄로 감정·소셜 포인트를 줍니다. 종이처럼 따뜻한 오프화이트 위에 올라갑니다.

시안 허브 A / B / C 비교 실물 샘플

Paper → Page Deep → Soft → Mute → Mint → Deep → Coral → Ink · 소스: css/style.css, docs/ui-mockups/themes.js (theme A)

사용 원칙

  • 그린(--green)은 CTA·선택·활성 상태에만 씁니다. 장식용으로 남발하지 않습니다.
  • 코랄(--coral)은 좋아요·하트·감정 포인트용입니다. 브랜드 CTA와 역할을 나눕니다.
  • 본문·제목은 Ink 계열, 보조 설명은 Muted, 구분선은 Line만 사용합니다.
  • 페이지·메뉴 캔버스는 Page Deep(--page-deep / --app-page-bg), 카드·시트 표면은 White(--card), 시트·입력 등 연한 면은 Paper(--page)로 계층을 만듭니다.
