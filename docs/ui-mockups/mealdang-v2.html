밀당 시안 v2

한 스크롤에 묶여 있던 분석과 참견을 헤더 탭으로 분리했습니다. meal-dang 오른쪽에 탭을 두고, 각 화면만 온전히 보여 줍니다.

허브 밀당 모먼트 밀로그 라운지 마이 폰만

이 시안에서 바꾼 것

  • 헤더 탭: 분석 / 참견 meal-dang 워드마크 바로 오른쪽에 pill 탭. 한 화면에는 한 구역만 표시.
  • 참견 = soft-green 풀 뷰 캐릭터·말풍선·코멘트·KPI를 soft-green 면 안에 묶음.
  • 분석 = page + 흰 카드 세그먼트·차트는 `var(--page)` 위 흰색 카드. 식사 / 간식 / 건강 / Best.
  • 기간 서브탭 = 공통 soft-green active · 선택 텍스트 검정 · 컴팩트 높이. `최근 1주 / 주간 / 월간 / 연간 / 더`.
  • 진입: 하단 네비 첫 번째 · 밀당 하단 5탭(밀당·모먼트·밀로그·라운지·마이)으로 시안이 연결됩니다.
