모먼트 시안 v2

홈 피드 시안과 같은 화이트·카드 톤으로 모먼트를 정리한 제안입니다. 인스타형 사진 오버레이를 줄이고, 사진 + 아래 메타/소셜로 개인 기록과 톤을 맞춥니다.

← 홈 시안 라운지 밀당 폰만 보기

이 시안에서 바꾼 것

  • 탭 자리: 모먼트 = 1단 메뉴 하단: 홈 / 모먼트 / 기록 / 라운지 / 마이. 개인 일간 뷰는 홈의 날짜 탭·캘린더로 흡수하는 안.
  • 화이트 헤더 + moment 워드마크 녹색 크롬 제거. 우측은 흔적 필터 칩 + 알림.
  • 카드형 피드 (오버레이 ↓) 작성자·메뉴·코멘트·좋아요를 사진 아래 본문으로. 다장 배지·페이지 닷만 사진 위에 유지.
  • 메타 표기 통일 홈과 같이 점심 · 장소 + 메뉴 타이틀. 기존 휠 라벨(YYYY:MM:DD:…)은 시안에서 제외.
  • 흔적 필터 정제 ♥ / 댓글 / 북마크를 pill 칩으로. 접기·펼치기 대신 상시 노출.
