없음 1건 2건 3+ 선택

닫기: 배경 딤 · ESC · 1건 = soft · 2건 = mute · 3건+ = solid

1. 헤더

‹ 제목 › 대칭. X 없음. chevron은 Lucide, 원형 테두리 버튼(기록 날짜 피커와 동일).

2. 날짜 셀

기록 있는 날만 원형. 1 = soft, 2 = mute, 3+ = green. 선택은 --green.

3. 팔레트

민트 위주(--green / --green-soft / --c1). 주말은 --coral. 셸은 --line / --shell-dim.

X 제거 · backdrop/ESC 원형 + 민트 농도 Soft Mint only
