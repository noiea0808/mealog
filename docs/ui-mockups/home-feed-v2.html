홈 피드 시안 v2

제공해 주신 시안 톤을 기준으로, mealog 브랜드·기존 기능을 Reflex “라이프스타일 다이어리” 방향으로 정리한 프로토타입입니다.

이 시안에서 바꾼 것

  • 화이트 헤더 녹색 그라데이션 크롬 제거. 브랜드는 로고·선택·FAB·활성 탭에만.
  • 세로형 피드 카드 사진 있으면 와이드 이미지, 없으면 원형 아이콘 + 텍스트.
  • 캘린더 선택 원 밀도 도트는 아주 작게만 유지(습관 힌트). 전체/일간 토글 제거.
  • 정보 단순화 아침 · 장소, 별 아이콘, 태그 1~2개.
  • 하단 탭 + 라벨 홈 / 모먼트 / 기록 / 라운지 / 마이. (통계·밀당은 마이 하위 후보)
