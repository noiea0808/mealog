라운지 시안 v2

홈·모먼트와 같은 화이트 헤더·라운드 카드 톤으로 라운지를 정리한 제안입니다. 기본 화면은 게시판이고, 서브탭으로 밀톡·공지를 유지합니다.

허브 밀당 모먼트 밀로그 마이 폰만 밀톡 미리보기

이 시안에서 바꾼 것

  • 탭 자리: 라운지 = 1단 메뉴 하단을 밀당 / 모먼트 / 밀로그 / 라운지 / 마이로 연결. 시안 허브·하단 탭으로 화면 간 이동.
  • 화이트 헤더 + lounge 녹색 서브탭 그라데이션 제거. 서브탭은 soft green pill.
  • 게시판 카드 라운드화 풀폭 사각·좌측 액센트 → 18px 카드. 사진 있으면 우측 썸네일.
  • 카테고리 칩 밑줄 태그 → pill (#전체 #먹는 #가벼운 #무거운 #치프에게).
  • 밀톡 유지 FAB 없는 인라인 컴포저. 말풍선만 soft green / 흰 카드로 톤 맞춤. (좌측 링크에서 미리보기)
