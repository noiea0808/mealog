# 앱 아이콘 적용 가이드 (베타/스토어 배포용)

설치 시 홈 화면에 보이는 앱 아이콘을 적용하는 방법입니다.

## 1. 소스 이미지 준비

- **파일**: 정사각형 이미지 1장 (PNG 또는 JPG)
- **크기**: **1024×1024 픽셀** 이상 권장 (작으면 품질 저하)
- **내용**: 투명 배경이면 Android에서 기본 배경색이 들어갑니다. 배경색을 지정하려면 아래 생성 시 옵션 사용.

## 2. 프로젝트에 넣기

만든 아이콘 이미지를 아래 이름으로 **프로젝트 루트의 `assets` 폴더**에 넣습니다.

```
mealog/
  assets/
    icon-only.png   ← 여기에 1024×1024 아이콘 파일 넣기
    fonts/          (기존 폰트 폴더)
```

파일명은 반드시 **`icon-only.png`** (또는 `icon-only.jpg`)로 맞춰주세요.

## 3. 아이콘 자동 생성

터미널에서 한 번만 실행하면 됩니다.

```bash
npm run icons:generate
```

이 스크립트가 Android용 여러 해상도 아이콘과, 웹용 favicon/manifest 아이콘을 자동으로 만들어서 적용합니다.

### 배경색 지정 (선택)

Android 어댑티브 아이콘의 **배경색**을 바꾸려면:

```bash
npx capacitor-assets generate --iconBackgroundColor "#10b981"
```

원하는 색상 코드로 `#10b981` 부분을 바꾸면 됩니다. (MEALOG 테마색 예시)

## 4. 앱에 반영

**스테이징(베타) 빌드**는 번들 모드로 동작하며, 빌드 시 아이콘 소스가 있으면 자동으로 아이콘을 생성합니다. 아래 한 번만 실행하면 됩니다.

```bash
npm run cap:build:staging
```

- 아이콘: `assets/icon-only.png`가 있으면 빌드 과정에서 자동 생성 후 적용됩니다.
- 앱 내용: 원격 URL이 아닌 **앱 안에 번들된 www**를 사용해, 브라우저가 따로 뜨지 않습니다.

수동으로 아이콘만 먼저 생성하려면:

```bash
npm run icons:generate
```

## 요약

| 단계 | 작업 |
|------|------|
| 1 | 1024×1024 아이콘 이미지 준비 |
| 2 | `assets/icon-only.png` 로 저장 |
| 3 | `npm run cap:build:staging` 실행 (아이콘 자동 생성 + 번들 APK 빌드) |

이미지만 준비해 두었다면 2번에서 `assets/icon-only.png`로 복사한 뒤 3번만 실행하면 됩니다.
