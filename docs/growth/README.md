## 진단 요약 (2026-09-06)

- **제품은 붙는다**: DAU/MAU 26.4%, 신규 D7 38% / D14 32%. 건강·기록 앱 통상치보다 높다.
- **유입이 없다**: 신규 하루 2명, 전부 오가닉. 공유 텍스트에 링크 없음, 딥링크 없음, 공개 페이지 없음, 이벤트 계측 0건.
- **사용자는 두 부류**: 음식 일기형(A) 25명, 몸 상태 추적형(B) 20명, 어느 축도 안 쓰는 저활동(U) 43명.
  자리 잡은 A·B는 똑같이 남는다. 신규에서는 B가 D7 70% vs A 36%(p=0.20, 방향성만), U는 24%(B 대비 p=0.02).
- **결론**: 획득 실험은 B부터, 우산 메시지는 "판단하지 않는 식사 기록", 온보딩은 "축 고르기". 새는 독(공유·딥링크·계측)을 2주 안에 막고 나서 채널을 판정한다.
