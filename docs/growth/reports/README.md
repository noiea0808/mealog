# 게시된 보고서 페이지 원본

여기 HTML은 claude.ai 아티팩트로 게시한 페이지의 **원본**이다.
게시본을 고치려면 이 파일을 고친 뒤 같은 주소로 다시 게시한다(주소가 유지된다).

| 파일 | 페이지 | 주소 |
|---|---|---|
| `growth-plan.html` | 밀로그 성장 계획 | https://claude.ai/code/artifact/6e731bef-4b0a-413a-89fa-2b9ed038c20e |
| `ad-campaign-report.html` | 광고비 146만원 결산 | https://claude.ai/code/artifact/3bf2d7bc-abf7-41c7-968d-4bb96cd22019 |

두 페이지 모두 **기본은 비공개**다. 남에게 보내려면 페이지의 공유 메뉴에서 공개로 바꾼다.
외부 제출용이면 링크보다 브라우저 인쇄(PDF 저장)가 안전하다 — 다만 아직 인쇄용 스타일은 넣지 않았다.

내용의 정본은 옆 폴더의 마크다운 문서다. 이 HTML 은 **훑어보기용 요약**이고,
수치를 고칠 일이 생기면 마크다운과 함께 고쳐야 두 곳이 갈라지지 않는다.
