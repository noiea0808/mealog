## 2. 실제로 남은 사람 — 관리자 코호트와 대조

**표면 숫자만 보면 성공이다.** 구글 애드 설치당 974원은 통상 기준(1,000~3,000원)보다 싸다.
그러나 가입 주차별 코호트를 겹쳐 보면 다르다.

  같은 시기 순수 유입 코호트는 38~44%였다. **8배 차이.**
- 3월 3주는 가입한 26명 중 17명이 **가입한 주에 아무것도 적지 않았다**(가입주 기록률 35%, 전체 최악).

> 판정 기준으로 삼은 활성 사용자 단가 8,000원의 스무 배가 넘는다.

## 3. 왜 이렇게 됐나

**① 구글에게 「설치」를 시켰다.**
앱 캠페인은 목표로 준 것을 정확히 최적화한다. 목표가 설치면 **설치할 사람**을 찾지 **쓸 사람**을 찾지 않는다.
앱 캠페인은 다른 앱(게임 등) 안의 광고 지면에도 나가고, 거기서 잘못 눌러 설치하거나 보상 때문에 설치하는
사람이 대량으로 나온다. 이들은 앱을 열지 않는다.

**② 노출 규모는 효과와 무관했다.**
다모앙 1,767만 노출(100만원) < 구글 3.3만 노출(26만원). **노출이 500배 많은데 결과는 더 나빴다.**
관심 없는 사람에게 500번 보여주는 것보다 관심 있을 사람에게 한 번 보여주는 게 낫다.

**③ 다모앙 클릭의 약 40%가 iOS였다.**
밀로그는 안드로이드 앱뿐이라 **약 2,600건은 처음부터 설치가 불가능한 클릭**이었다. 예산의 40%가 그냥 버려졌다.

**④ 계측이 없어 사후 추정만 가능하다.**
유입 경로를 저장하지 않아 "이 사용자가 어느 광고로 왔는지"를 개인 단위로 알 수 없다.
코호트 크기 변화로 역산하는 수밖에 없었다.

## 4. 다음 광고 전에 반드시

| | 지킬 것 |
|---|---|
| 1 | **목표를 「설치」가 아니라 「가입 완료」 또는 「첫 기록 저장」으로.** 단가는 오르지만 그게 진짜 숫자다 |
| 2 | 그러려면 **Firebase Analytics 이벤트가 먼저**다(B-5). 자체 계측 `usageDaily`는 Firestore라 광고가 못 본다 |
| 3 | 모든 링크에 **UTM 필수** |
| 4 | 판정은 설치 단가가 아니라 **활성 사용자 단가**(가입 후 3일 내 기록 3건 + 축 1개). 8,000원 이하면 계속, 15,000원 넘으면 중단 |
| 5 | **한 채널씩 2~3주.** 동시에 열면 뭐가 효과였는지 알 수 없다 |
| 6 | iOS 대응이 없으면 **안드로이드만 타겟팅**. 아니면 예산의 40%가 버려진다 |

⚠ **주의**: 지금 가입이 하루 2~3명이다. 구글이 "가입할 사람"을 학습하려면 하루 10건 이상의 전환 신호가 필요하다.
**이벤트를 붙여도 당분간은 구글이 배울 데이터가 부족하다.** 유료 광고는 오가닉으로 규모를 좀 키운 뒤가 낫다.

## 5. 아직 확인 못 한 것

- **구글 애드의 「전환」 정의** — 설치인지 다른 인앱 이벤트인지. §2 해석의 전제다.
