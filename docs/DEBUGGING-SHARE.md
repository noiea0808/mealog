# SNS 공유 실패 시 확인 방법

앱에서 모먼트(앨범) SNS 공유가 실패할 때, 원인을 확인하는 방법입니다.

## 1. 토스트 메시지 확인

실패 시 토스트에 **어느 단계**에서 실패했는지 나옵니다.

- **이미지 불러오기 단계**: 앱이 Firebase Storage에서 이미지를 가져오지 못함 (네트워크/CORS 등)
- **파일 저장 단계**: Capacitor Filesystem에 캐시 저장 실패 (용량/권한 등)
- **공유 창 열기 단계**: Share 플러그인 호출 실패 (URI 형식/권한 등)

토스트 뒤에 붙는 영어 메시지도 함께 확인해 두면 좋습니다.

---

## 2. Chrome 원격 디버깅 (Android)

가장 확실한 방법입니다. PC에서 기기 WebView의 콘솔을 볼 수 있습니다.

1. **기기**: 설정 → 개발자 옵션 → **USB 디버깅** 켜기
2. **USB**로 기기와 PC 연결
3. **PC Chrome** 주소창에 `chrome://inspect` 입력 후 접속
4. 기기에서 **MEALOG 앱 실행** 후, 공유 버튼 눌러 실패 유도
5. `chrome://inspect` 화면에서 **mealog** / WebView 항목 옆 **inspect** 클릭
6. 열린 개발자 도구에서 **Console** 탭 선택
7. 빨간색으로 출력된 `sharePhotosToExternal(네이티브) 실패:` 로그 확인
8. 콘솔에 **`window.__lastShareError`** 입력 후 Enter → 저장된 오류 객체 확인

`__lastShareError` 예시:
- `step`: 실패한 단계 문자열
- `message`: 에러 메시지
- `stack`: 스택 트레이스

---

## 3. 스테이징 웹에서 테스트

앱 대신 **브라우저**에서 스테이징 URL로 접속해 공유를 시도해 볼 수 있습니다.

- 브라우저에서는 **Web Share API**(navigator.share)를 사용합니다.
- 여기서 성공하면: 앱(네이티브) 쪽 Share/Filesystem만 문제일 가능성이 큽니다.
- 여기서도 실패하면: 이미지 URL fetch(CORS 등) 또는 공통 로직 쪽을 의심할 수 있습니다.

---

## 4. 확인 후 공유해 주면 좋은 정보

- 토스트에 나온 **단계 이름** (이미지 불러오기 / 파일 저장 / 공유 창 열기)
- 토스트에 나온 **에러 메시지 일부** (가능하면 전부)
- Chrome 원격 디버깅에서 본 **`window.__lastShareError`** 내용 (복사해서 보내주셔도 됨)
- 사용 중인 **Android 버전**, **기기/제조사** (가능하면)

이 정보가 있으면 원인 좁히고 수정 방향을 제안하기 쉽습니다.
